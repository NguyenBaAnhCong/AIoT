Trong backend/src/routes.js:

1. Cạnh các import route khác, thêm:
   import gatewayRoutes from './modules/gateway/gateway.routes.js';

2. Tại dòng ghi chú "TV2: thêm dòng của mình ở đây", thêm:
   api.use('/gateway', gatewayRoutes);

Route đầy đủ: POST /api/v1/gateway/ingest

Gateway simulator gửi sensor_code S01, S02, S03. Các mã này có trong dữ liệu demo của repository chính.
Không đưa API key vào mã nguồn. Đặt GATEWAY_API_KEY trong file .env gốc.
